# Assets

All current art is **placeholder art** generated by
`tools/art/generate_placeholder_art.py` (Pillow + numpy). Regenerate it with:

```sh
pip install pillow numpy
python3 tools/art/generate_placeholder_art.py            # everything
python3 tools/art/generate_placeholder_art.py --only props
```

The network policy for this build blocked the usual CC0 sources (Kenney, OpenGameArt),
so everything was drawn by the script instead. That keeps the style consistent and
licence-free. Any file can be replaced.

## Replacing art

Data files reference images by path, so there are two options:

1. **Overwrite the PNG** at the same path. Godot re-imports it automatically.
2. **Point the data at a new file**: change `texture` in `terrain.json` / `props.json`,
   or `art.portrait` / `art.sprite` in a character sheet. Paths can be `res://...` or
   any readable file path (such as `user://...`).

A missing file shows as a magenta checkerboard and logs a warning, so broken references
are easy to spot.

## Specs

| Kind | Location | Size | Notes |
|---|---|---|---|
| Terrain | `assets/terrain/*.png` | 256×256 (other sizes are resized) | Must be **seamless**. Sampled in world space at 1 texel per pixel and blended with neighbouring terrain by `terrain_blend.gdshader`. |
| Props | `assets/props/*.png` | any | `origin` in `props.json` is the pixel placed on the anchor hex centre. Include the ground shadow in the image. |
| Character sprites | `assets/characters/*.png` | 48×64 | Front-facing. Feet at `(24, 58)` by default (`art.sprite_origin` to change). Flipped horizontally when walking left. Shadow and selection ring are drawn by code. |
| Portraits | `assets/portraits/*.png` | 128×160 | Shown at 64×80 in the sidebar (cropped to fill). |

Hex size is 32 px corner radius by default (55×64 px per hex), set by `hex_radius` in
`game_config.json`. Sprite scale is independent of it.

(a test checks this). The ground line where the front wall meets the ground is the
`origin`, and the roof extends upward in 3/4 view. `bridge_planks.png` is a spare
plank texture kept for interior floors in Phase 2.
